Sound Board

Every sound event a player or the edit emits (34 emitted, 34 in all, 0 with no sound), where it is emitted, what plays today, and all 30 vendored sounds as candidates. Pick a type, then for each event a sound and a level, and how many sfx a film of that type gets. Copy your picks and paste them into chat. Nothing here changes a mapping or a gain.

"Today" is assets/sfx/map.json, which every style's stem plays (the library graph is seeded from it, so its FITS gain is the same level) and which the edit's library cast and the Atlas, Handmade and Studio Minimal laws play. The Studio Cut plays the owner's pack, assets/sfx-style1/map.json, shown beside it. Levels are the RMS each hit is set to in the SFX stem (dBFS), before the stem's +6 dB. ▶ plays a file as it is; Hear at level plays your pick as the mixer would place it (RMS to the level, peak ceiling -6 dBFS, +6 dB stem). Rows marked with a blue edge are emitted by the type you are on.
