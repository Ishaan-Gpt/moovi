# Ideation: never the first idea

The first idea for any shot is the one every template, stock pack and AI would produce. Ideas 2–3 are its variations.
The good ones usually show up at 4–5, once the obvious ones are out of the way.

## The 5-idea drill (per shot, transition, layout, text treatment, icon)
Write them down, numbered, one line each:
1. **The obvious one.** Name it so you can avoid it (e.g. "text fades in centred").
2. **The polished obvious.** The same idea done well (e.g. "word-by-word blur-in").
3. **The reference's idea.** What the reference did here.
4. **Change the medium or the physics.** Make it real, tactile or physical: the word is printed, poured, stamped, magnetised,
   shattered, folded, projected, written by the product itself, revealed by light, ...
5. **Make it mean something.** The visual *is* the message: the verb acts itself out, the object turns into the next
   shot's object, the brand's own UI performs the transition, the caption chips ARE the typography, ...

Pick from 4 or 5, or fuse 3 + 5. Then run the jealousy test: would the reference's designer wish they'd done it?
If it could appear in any other brand's video unchanged, it is still generic. Make it specific to this product.

## Sources for ideas 4–5
- The product's own mechanics (CaptionsEasy: word timestamps, caption chips, a playhead, the look picker, a waveform, an export bar).
- Physical metaphors (paper, light, glass, ink, magnets, liquid, string).
- Camera grammar: one-take, pull-out reveals, match cuts, a scale change across 3 orders of magnitude.
- Sound-first: design the visual so it is triggered by a sound (a click, a pop, a swoosh).
- Mix references: a showreel transition + an editorial layout + a product UI move.

## Banned as a final choice (allowed only as idea #1 to be rejected)
Centred fade-in, generic slide-up, spinning logo, stock "glitch", lens flare, neon-outline text, confetti, a plain
card grid, emoji as icons, default library icon sets used untouched, the AI-default palette (blue / orange / cream /
navy + ice blue / neon on black; see palette.md), and any saved style, kit or preset applied without asking "can something be better?".
